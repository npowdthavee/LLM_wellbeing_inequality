# Large Language Models Substantially Compress Well-being Dispersion but Largely Preserve Its Socioeconomic Structure

Replication code for the project **Large Language Models Substantially Compress Well-Being Dispersion but Largely Preserve Its Socioeconomic Structure**.

The study examines whether large language models (LLMs) preserve the socioeconomic structure of human well-being heterogeneity even when their predicted responses are substantially less dispersed than human responses. The main analyses use World Values Survey (WVS) Wave 7 data and compare observed life satisfaction with respondent-level predictions from six LLMs.

## Preregistration

The primary study was preregistered on AsPredicted:

https://aspredicted.org/sf62bj.pdf

The primary preregistered analyses focus on the relationship between household income position and well-being inequality after accounting for model-specific compression.

A separately preregistered follow-up mechanism experiment using Claude Sonnet 5 is available here:

https://aspredicted.org/5hg8ba.pdf

That follow-up tests whether the preserved income-dispersion gradient is generated by the explicit income cue itself or can be reproduced from information elsewhere in the respondent profile. The linear counterfactual-income sweep and income-ablation analyses were preregistered. The quadratic characterization of the counterfactual sweep, the endpoint-to-minimum dispersion ratio, and the Gemini and DeepSeek income-ablation replications were conducted post-preregistration.

Analyses of distributional tails, country-level gradient fidelity, generalisation to other socioeconomic and psychosocial characteristics, and the OLS/Lasso benchmark are exploratory or benchmarking analyses.

## Data

The study uses **World Values Survey Wave 7** data. The WVS data are not redistributed in this repository. They can be obtained from the World Values Survey:

https://www.worldvaluessurvey.org/WVSDocumentationWV7.jsp

The final common analysis sample contains **93,901 respondents from 66 countries and territories** with valid responses for life satisfaction (Q49) and household income group (Q288).

The main outcome is life satisfaction (Q49), measured from 1 (completely dissatisfied) to 10 (completely satisfied). Household income position (Q288) ranges from 1 (lowest income group) to 10 (highest income group within the respondent's country).

## LLMs

Predictions for the main six-model analysis were collected between **20 and 23 September 2026** using:

- GPT-5.6 Luna
- Claude Sonnet 5
- Gemini 3.8 Flash
- DeepSeek V4.1 Flash
- Qwen 3.7 Plus
- Gemma 4 31B

Each model received the same respondent profile and was asked to predict the respondent's life satisfaction on the WVS 1-10 scale. The notebooks record the exact model identifiers, prompts, API endpoints, and output-audit information used for the study.

## Repository structure

### `1_WVS_prepare.ipynb`

Prepares the WVS Wave 7 data, constructs respondent profiles, defines the common analysis sample, and creates the input file used for LLM prediction. The life-satisfaction outcome itself is excluded from the respondent profiles to prevent leakage.

### `2_WVS_predict.ipynb`

Sends respondent profiles to one LLM at a time and saves respondent-level predictions. The notebook contains the exact prompt, model configuration, endpoint settings, batching logic, and technical audit information.

Required environment variables are:

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
- `GEMINI_API_KEY`
- `DEEPSEEK_API_KEY`
- `DASHSCOPE_API_KEY`
- `DEEPINFRA_API_KEY`

API keys are not stored in this repository.

### `3_WVS_Human_LLM_Analysis.ipynb`

Runs the main human-LLM analyses, including raw income gradients in mean life satisfaction and well-being dispersion, scale-normalised dispersion profiles, preregistered profile-comparison tests, country-fixed-effect RIF variance regressions, RIF-Oaxaca decompositions, weighting robustness checks, distributional-tail analyses, and country-level gradient-fidelity analyses.

### `4_WVS_Generalization_Other_Characteristics.ipynb`

Extends the scale-normalised heterogeneity analysis to employment status, educational attainment, marital status, and perceived freedom and control.

### `5_WVS_OLS_Lasso_NonLLM_Benchmark.ipynb`

Implements the post-preregistration supervised benchmark using five-fold out-of-fold OLS and Lasso predictions trained on observed WVS life satisfaction. The notebook compares overall dispersion compression and normalized income-dispersion structural fidelity with the human benchmark and the six LLMs. These models are diagnostic benchmarks rather than directly comparable zero-shot substitutes because they are trained on observed life-satisfaction outcomes from the study sample.

### `6_WVS_Multimodel_Mechanism_Income_Ablation.ipynb`

Implements the follow-up income-cue mechanism analysis. It reconstructs the fixed stratified sample of 2,000 WVS respondents (200 per original income group), reuses the frozen Claude Sonnet 5 mechanism predictions, and analyzes two preregistered manipulations: a counterfactual income sweep in which each respondent is assigned all ten income positions while every other profile characteristic is held fixed, and an income-ablation condition in which Q288 is removed from the profile.

The notebook also runs the post-preregistration no-income replications for Gemini 3.8 Flash and DeepSeek V4.1 Flash, applies the same full-sample human income-group weights used in the primary normalization, and conducts 1,000 paired country-cluster bootstrap replications. Existing Claude mechanism data are reused by default; `ALLOW_NEW_CLAUDE_CALLS = False` prevents accidental recollection.

## Reproduction order

Run the notebooks in numerical order:

1. `1_WVS_prepare.ipynb`
2. `2_WVS_predict.ipynb` separately for each model
3. `3_WVS_Human_LLM_Analysis.ipynb`
4. `4_WVS_Generalization_Other_Characteristics.ipynb`
5. `5_WVS_OLS_Lasso_NonLLM_Benchmark.ipynb`
6. `6_WVS_Multimodel_Mechanism_Income_Ablation.ipynb`

Notebook 6 reuses original observed-income predictions from Notebook 2 and the frozen Claude mechanism outputs when those files are present. Its Gemini and DeepSeek no-income arms are checkpointed and resumable.

## Main methodological distinction

The paper distinguishes between two aspects of distributional fidelity:

- **Scale fidelity:** whether a model reproduces the overall amount of human dispersion.
- **Structural fidelity:** whether it reproduces where relatively greater and lower dispersion occurs across social groups.

To study structural fidelity independently of overall compression, within-group standard deviations are normalised by each source's own weighted-average standard deviation, using fixed human group shares as weights.

With one prediction per respondent profile, the dispersion of LLM predictions reflects variation across heterogeneous profiles rather than repeated stochastic variation from multiple generations of the same profile.

## Reproducibility

The notebooks contain the data-processing, prompting, prediction, primary-analysis, exploratory-analysis, supervised-benchmark, and mechanism-analysis code used for the paper. Stored execution outputs have been removed from the repository copies; code and markdown cells are retained. Because the WVS microdata, model outputs, and API credentials are subject to their respective access, licensing, or cost constraints, they are not included in the repository.
